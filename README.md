# Оружейная

Подбор лучшего шмота по уровням для World of Warcraft: The Burning Crusade,
Anniversary-реалмы. Выбираешь класс и фракцию, двигаешь ползунок уровня — видишь,
что должно быть надето на персонаже, как на экране персонажа в игре.

Появившееся на этом уровне помечено словом «новое», под ползунком перечислены
поменявшиеся слоты. У каждой вещи написано, когда её менять — «сменится на 42», —
по этому и понятно, что стоит покупать.

Шмот тут меняется почти каждый уровень, а скупать всё подряд незачем — поэтому
в шапке есть переключатель **«Сейчас / Надолго»**. В режиме «надолго» на слоте
стоит не лучшая вещь уровня, а та, что дольше всех держится в пределах 10% от
лучшей: подпись читается как «с 33 до конца · 28 ур.», а под ней шкала уровней
с закрашенным отрезком жизни и засечкой там, где ты сейчас. Отрезок может
начинаться и правее засечки — значит, вещь на вырост, но ждать её стоит. По
щелчку раскрываются остальные долгожители слота, и их полоски стоят друг под
другом: где кончается одна, там начинается следующая — это и есть план покупок.

Нужной вещи на аукционе может не быть — тогда щёлкни по слоту: под ним
раскроются до десяти замен, и у каждой написано, сколько от лучшего варианта
остаётся, «87%». Так видно, стоит ли ждать саму вещь или взять что попроще.

Вещи с суффиксом помечены словом «ролл»: у «of the Tiger» бывает несколько сил,
на аукционе все лоты названы одинаково, а статы у них разные. Такая вещь стоит
в списке по среднему роллу, рядом написан разброс — «ролл 75-100%», а в подсказке
статы идут вилкой, «+3-4 к ловкости». При равном проценте вперёд ставится вещь с
фиксированными статами: её плюсы достанутся точно.

Класс, уровень, фракция, вес выносливости и режим лежат в адресе
(`?faction=horde&class=rogue&level=40&stam=2&mode=long`), поэтому ссылкой на
конкретный список можно поделиться.

Считаются только вещи, которые **реально можно купить на аукционе**:

- BOE или вовсе без привязки (`bonding` 2 или 0);
- не требуют профессии, чтобы надеть (`RequiredSkill = 0`);
- достижимы в игре — падают, продаются, даются за квест или крафтятся;
- доступны выбранной фракции.

Оценка идёт **по ДПС**, веса статов — из симулятора
[wowsims/tbc-new](https://github.com/wowsims/tbc-new). В чистом ДПС выносливость
не весит почти ничего, а качающемуся в одиночку она нужна, поэтому её вес вынесен
в отдельный ползунок: от «не считаем» до «наравне с главным статом».

По умолчанию стоит совет для соло: половина главного стата в ближнем бою и
четверть у тех, кто бьёт издалека, — по ним реже попадают. Чистый ДПС это крайнее
левое положение, оно для группы и данжей.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm run build
```

Данные лежат в репозитории готовыми (`src/data/bis.json`), пересобирать их для
работы приложения не нужно.

Проверки — по одной или все сразу:

```sh
npm run typecheck     # tsc --build, strict + noUncheckedIndexedAccess
npm run lint          # oxlint
npm run format        # oxfmt, с --check не правит, а проверяет
npm run test          # vitest, --coverage для отчёта
npm run check         # всё перечисленное подряд
```

То же самое гоняется в CI на каждый push и pull request
([`.github/workflows/ci.yml`](.github/workflows/ci.yml)).

## Устройство

React 19 + TypeScript, сборка Vite, тесты Vitest, линтер и форматтер из
семейства oxc. Стек и настройки — в `package.json`, `tsconfig.app.json`,
`.oxlintrc.json`, `.oxfmtrc.json`.

```
src/
  main.tsx       точка входа: Suspense на загрузку, ErrorBoundary на ошибку
  Armory.tsx     ждёт данные и отдаёт их приложению
  App.tsx        сборка экрана; чистая функция от данных, поэтому тестируется
                 без сети и моков
  components/    строка экипировки, список замен, тултип, полоска жизни,
                 ползунки, панель выбора, сводка
  hooks/
    useUrlState  класс, уровень, фракция, вес выносливости и режим в адресе
  lib/
    bis.ts       разворачивание списков и сумма статов
    diff.ts      разница между соседними уровнями и срок жизни вещи -
                 и «сменится на 42», и отрезки для режима «надолго»
    text.ts      подписи: «сменится на 42», «с 33 до конца · 28 ур.»
  game/          справочники: классы, слоты, статы, режимы, тултип
  data/
    schema.ts    типы формата bis.json
    load.ts      загрузка данных отдельным запросом
    bis.json     посчитанные списки, 4.6 МБ
  styles/        оформление под игровую Оружейную, по файлу на блок
  test/          фикстура для тестов
public/
  fonts/         FRIZQT___CYR и MORPHEUS_CYR - шрифты интерфейса из клиента
tools/           генерация bis.json, см. tools/README.md
```

`bis.json` подключён как ассет (`?url`), а не импортом: иначе четыре мегабайта
запеклись бы в бандл, и браузер разбирал бы их как JavaScript до первой
отрисовки. Отдельным файлом он приезжает параллельно и кешируется по хешу в
имени — сам бандл при этом 213 КБ.

Иконки предметов и классов подтягиваются с CDN Wowhead по имени файла из
клиентских данных, в репозитории их нет.

### Формат данных

```jsonc
{
  "items": {
    "12640": {
      "name": "Lionheart Helm", "q": 4,      // q - качество, 0 серое ... 5 легендарное
      "lvl": 61, "ilvl": 65,                 // требуемый уровень и уровень предмета
      "icon": "inv_helmet_28",
      "inv": 1, "cls": 4, "sub": 4,          // слот, класс и подкласс предмета
      "boe": true, "uniq": false,
      "armor": 645, "dura": 100              // урон и скорость - только у оружия
    }
  },
  "stam": [0, 0.25, 0.5, 1],                   // положения ползунка выносливости
  "rows": [                                    // вещи, каждая по одному разу
    { "item": 12640, "sfx": null,
      "stats": { "Strength": 18, "CritRating": 28, "HitRating": 20 },
      "low": { "Strength": 16 }                // самый бедный ролл, если вилка есть
    }
  ],
  "lists": [                                   // варианты на слот: номер строки
    [[0, 100], [17, 88, 75, 100], [25, 91]]    // и сколько от лучшего остаётся, %
  ],
  "bis": {
    "alliance": {
      "warrior": {
        "60": [                                // по набору на положение ползунка
          { "head": 0, "neck": 12 }            // слот -> номер списка
        ]
      }
    }
  }
}
```

`sfx` — случайный суффикс вроде `of the Tiger`, если он есть. Тогда статы в
`stats` уже посчитаны вместе с ним (это самый богатый ролл, бедный лежит в
`low`), а `item` указывает на базовый предмет — поэтому ссылка на Wowhead ведёт
на версию без суффикса.

На слот хранится не одна вещь, а список из 11: первая — та самая лучшая, за ней
до десяти замен на случай, когда её нет на аукционе. Рядом с номером строки
стоит доля от лучшего варианта в процентах.

У вещи с суффиксом статы выпадают при создании, поэтому она считается по
среднему роллу, а в данных лежит вилка: `low` — самый бедный ролл (`stats` при
этом самый богатый), и в списке после среднего процента идут ещё два — сколько
дают края вилки. Если разброс приходится на статы, которые классу не нужны,
очки от ролла не зависят и этих двух чисел нет.

Ползунок выносливости меняет веса, а значит и сами списки, поэтому на каждый
уровень посчитано четыре набора — по числу его положений (`stam`, доля главного
стата класса). И строки, и целые списки повторяются на соседних уровнях, поэтому
хранятся по одному разу, а уровень ссылается на них номерами:
`bis.alliance.warrior['60'][stam].head` → `lists[…]` → `rows[…]`.

Слоты: `head`, `neck`, `shoulder`, `back`, `chest`, `wrist`, `hands`, `waist`,
`legs`, `feet`, `finger1`, `finger2`, `trinket1`, `trinket2`, `ranged`, и оружие —
либо `twohand`, либо пара `mainhand` + `offhand`.

| Что | Источник |

| Предметы, статы, лут, вендоры, квесты, спеллы | [cmangos/tbc-db](https://github.com/cmangos/tbc-db), сборка SQLite |

| Картинки иконок | CDN Wowhead |
| Веса статов | EP-пресеты симулятора [wowsims/tbc-new](https://github.com/wowsims/tbc-new) |

Как пересобрать — в [tools/README.md](tools/README.md).

Оговорка про cmangos: это база эмулятора под оригинальный TBC 2.4.3. Контент
Anniversary тот же самый, но всё, что Blizzard поменяли специально для юбилейных
реалмов, оттуда не приедет.

## Что уже известно и багом не является

- **Аксессуары всегда пустые.** Среди BOE-тринкетов до 60 уровня нет ни одного с
  постоянными статами — у всех эффект по нажатию или прок.
- **Голова пустая до 24 уровня.** Шлемов в игре раньше нет. У воина и паладина
  до 40 в голове стоит ткань, кожа или кольчуга — латных шлемов на аукционе там
  ещё нет, а надеть броню полегче своего класса игра позволяет.
- **Плечи начинаются с 15**, шея с 13, кольца с 10; шея есть не на всех уровнях
  (у разбойника на 48 из 60).
- **На 1-9 уровне заполнены только тело и одно оружие.** Голова, плечи, шея,
  кольца и аксессуары так рано не встречаются, а левая рука пустая до 10: бой
  двумя руками раньше не выучить.
- **Списки фракций почти совпадают** — из 26 984 сравнённых слотов различаются
  377, полтора процента, и больше половины из них на уровнях 1-9: там шмот
  стартовых зон, а он у сторон разный. Дальше почти всё это мировой дроп и
  крафт, а он нейтральный.
- **Шмот меняется почти каждый уровень** — что-то новое появляется на 98% шагов
  уровня, в среднем меняется 5 слотов, медианная вещь живёт один уровень. Это
  особенность аукционного шмота с суффиксами, а не ошибка расчёта; поэтому
  срок замены показан у каждой вещи отдельно, а не общей строкой «замена на 42».
